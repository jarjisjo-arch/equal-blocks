# Equal Blocks Android Wrapper

This project wraps the web game in a native Android WebView.

Build from Android Studio:
1. Open this folder: `android-apk-wrapper`
2. Let Android Studio install/sync Gradle and Android SDK packages.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. The APK will be generated under `app/build/outputs/apk/debug/`.

The game file is stored at:
`app/src/main/assets/index.html`
